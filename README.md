# mid-autumn-2026
2026 中秋国风静态单页网站 ✨

在线预览：https://crunchy-apple.github.io/mid-autumn-2026/

## 简介
纯静态单页面，**无外部依赖、无第三方框架**，全部样式与脚本内置在 index.html。
深蓝色夜空国风主题，适配手机、电脑端。

### 页面功能
- 🌕 月亮：6秒呼吸发光动画，鼠标移动时光晕轻微跟随光标
- 🐰 简约SVG玉兔，持续上下缓慢浮动
- 🌸 桂花花瓣自动飘落，动态生成并自动销毁，不会堆积
- 📜 交互：点击月亮，切换中秋诗句与祝福寄语
- 🔗 页面底部 GitHub、Gitee 仓库跳转链接
- 📱 移动端自适应，全屏无滚动条，轻量化不卡顿
